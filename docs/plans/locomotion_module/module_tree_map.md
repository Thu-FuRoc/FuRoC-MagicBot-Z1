# 模块树使用说明

## 一、这不是实施清单，而是结构框架

当前这些模块页的作用是：

- 先把“运动控制小脑”搭成一个结构化模块树
- 告诉读者未来可以往哪些方向扩展
- 防止大家误以为当前 `Locomotion` 样例就是全部方案

它们现在更像：

- 专题入口页
- 规划页
- 模块占位页

而不是每一个都已经完整实现的训练项目。

## 二、为什么先建树，再填内容

因为如果先不把树搭出来，读者很容易把：

- 一个具体样例

误读成：

- 全部训练方案

先把模块树立起来，后续每个模块都可以逐步补：

1. 样例训练方案
2. 可复现配置
3. 指标图表
4. 对应示意图

## 三、当前树的推荐读法

1. 先看 `Locomotion` 入门样例
2. 再看模块化视角
3. 再看并列模块各自关注什么
4. 最后决定下一步要重点深化哪个模块
