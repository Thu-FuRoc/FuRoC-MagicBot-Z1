# 远程 Isaac Lab 录制、回传与 GIF

## 录制需求

当本地已经能播放，或者远端 Isaac Lab 已经能运行时，下一步通常是把结果整理成可分享素材。

## 两种常见路径

### 1. 本地直接播放

适合：

1. 快速检查
2. 录屏
3. 手动转 GIF

### 2. 远程 Isaac Lab 录制

适合：

1. 在远端稳定生成视频
2. 用统一环境录制
3. 回传本地后再二次加工

## 推荐流程

1. 在远端 Isaac Lab 录制 MP4
2. 下载回本地
3. 本地压缩或截段
4. 转成 GIF
5. 上传飞书

## 为什么这样做

因为飞书更适合挂轻量可预览素材，而不是直接依赖远端运行环境。
